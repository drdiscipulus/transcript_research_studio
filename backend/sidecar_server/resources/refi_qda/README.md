# Bundled REFI-QDA Project schema

`Project.xsd` is the official REFI-QDA Project 1.0 schema (release 18 March
2019), mirrored by the openqda/refi-tools repository from QDAsoftware.org.

- Source: https://github.com/openqda/refi-tools/tree/main/docs/schemas/project/v1.0
- Project implementation files: https://www.qdasoftware.org/project-implementation-files
- License: MIT (as declared by the mirror for the standard specification files)

The schema is bundled so QDPX exports can be validated locally without a
network request.
